# 评测机（演示）

**当前阶段**：第 3~4 天使用后端内置**假评测器**（`FAKE_JUDGE=true` 默认开启），无需启动本目录任何程序即可看到 提交→自动评测→终态 流转。

**替换计划**：第 4 天实现本目录真实演示评测机（judge_daemon.py 主循环：登录 → 拉任务 → 检出 → 取源码/数据 → g++ 编译 → 运行比对 → 回传），启动方式见 docs/api.md 第 4 节；启动后设置环境变量 `FAKE_JUDGE=false` 停用假评测器。

接口契约以 `docs/api.md` 为准（评测机接口：/api/v1/judge/*，judger 角色鉴权）。
